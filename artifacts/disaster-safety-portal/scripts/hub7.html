지진/화산

국내·외에서 발생한 지진의 위치, 규모, 진도, 발생시각 등의 데이터와 화산의 분화시각, 위치, 분연주높이 등의 데이터를 제공합니다.

  • 지진해일정보
  • 화산정보
api 상세
개요

지진정보는 국내에서 규모 2.0 이상인 지진이 발생한 경우 발표한 자료입니다.
국외지진정보는 구역 내 지역에서 규모 5.0 이상, 해역에 5.5 이상일 경우와 구역 외 지역에서 규모 6.0 이상, 해역에서 7.0 이상의 지진이 발생했을 경우 발표한 자료입니다.
요 소

(국내)발생시각, 발생위치, 규모, 발생깊이, 계기진도
(국외)발생시각, 발생위치, 규모, 발생깊이
지 점

(국내)국내에서 발생한 지진
(국외)구역내(북위 21°~45°, 동경 110°~145°) 및 그 외 국외지진

요청인자
데이터 기본 정보
인자명 의미 설명

frDate

시작시간

검색 시작시간 : 연월일+시(yyyymmdd+hh)(입력예: &frDate=20191001 또는 &frDate=2019100123)

laDate

종료시간

검색 종료시간 : 연월일+시(yyyymmdd+hh)(입력예: &laDate=20191002 또는 &laDate=2019100223)

msgCode

지진종류

전체 : 미입력, 111 : 지진조기경보, 212 : 지진속보, 102 : 지진정보, 103 : 지진정보(재통보), 104 : 국외지진정보,
213 : 국외지진조기경보(시범)(입력예: &msgCode=111,212)

cntDiv

국내여부

전체 : 미입력, Y : "국내", N : "국외" (입력예 : &cntDiv=Y)

arDiv

지역구분

전체 : 미입력, A : "지역", S : "해역" (입력예 : &arDiv=A)

eqArCd

지역상세

전체 : 미입력, A02 : 서울, A03 : 부산, A04 : 인천, A05 : 대전, A06 : 대구, A07 : 광주, A08 : 울산, A09 : 경기,
A10 : 강원, A11 : 충남, A12 : 충북, A13 : 경남, A14 : 경북, A15 : 전남, A16 : 전북
A17 : 제주, A18 : 세종, A99 : 기타, S02 : 동해, S04 : 서해, S03 : 남해, S99 : 기타해역 (입력예 : &eqArCd=A09)

nkDiv

북한여부

전체 : 미입력, Y : "북한", N : "북한아님" (입력예 : &nkDiv=N)
